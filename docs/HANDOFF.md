## 二、三条不可动摇的约束

来自 `CLAUDE.md`,违反了就是方向性错误:

1. **零二进制资产。** 仓库里只能有文本文件。贴图运行时用 shader / 程序化生成到
   `DataTexture`,音效用 Web Audio 合成。**写实和零资产不冲突** —— 现在的沥青、
   沙地、法线贴图全是运行时算出来的。
2. **改完必须自己看画面。** 跑 `npm run shoot`,然后用 Read 工具**真的打开那张 PNG**。
   编译通过 ≠ 画面正确。这个项目已经吃过好几次亏,见第五节。
3. **一个里程碑一个 PR。** 不要顺手做下一个里程碑的事。

### 视觉方向(2026-08 由人类改定)

原定的「低多边形」**已作废**,改为尽量接近实拍照片。天花板已经写进 `CLAUDE.md`:

- **能做到接近实拍**:光照(IBL、真实阴影、AO)、大气散射、PBR 材质、色调映射、后处理。
- **做不到实拍级**:复杂**造型**。手写 `BufferGeometry` 出不了照片级的载具外形,
  载具是明确的短板。别拿「照片级」去要求它。

## 三、代码地图

```
src/core/     引擎无关:定步长主循环、seeded PRNG、输入层、数学工具、测试接口
src/game/     玩法:载具物理、赛道生成与查询、相机、计时、数值
src/gfx/      渲染:大气、贴图生成、各种网格、配色
scripts/      截图脚手架
tests/unit/   逻辑测试(174 条)
tests/visual/ Playwright 截图冒烟(12 条)
```

### 几个关键文件

- **`src/game/tuning.ts`** — 所有手感与视觉数值的唯一来源,分 `VEHICLE` / `CAMERA` /
  `TRACK` / `SKY` 四段。**人类调手感只改这一个文件。** 每个值都写了「为什么是这个数」。
- **`src/game/groundQuery.ts`** — 向下地面查询的统一契约。物理、相机都只认这个接口,
  所以 `?course=flat`(M1 那块平地)能在不动物理代码的前提下切回去。
- **`src/game/course.ts`** — 赛道的两段式地面查询。**这是全项目最重要的不变量所在**,
  见下一节。
- **`src/game/vehicle.ts`** — 悬浮控制器。物理都在这儿,数值都不在这儿。
- **`src/gfx/textures.ts`** — 程序化 PBR 贴图生成器。

## 四、必须理解的三个不变量

破坏它们不会立刻报错,但会让整个项目慢慢烂掉。

### 1. 物理查询的面 == 渲染出来的面

`Course` 预先算好一张条带顶点网格(行=中心线采样,列=横向分档),**渲染网格和
`sample()` 吃同一张表、同一套三角划分**,`sample()` 返回的是所在三角面的精确平面
高度和面法线。

`tests/unit/course.test.ts` 拿 600 个三角形重心直接断言这一点。**别为了方便在
任何一边另算一套高度** —— 车会浮在你看到的路面上方,或者陷进侧倾里,而且极难查。

赛道外的地形是例外:噪声高度 + 有限差分法线,没做到面级精确。那里是出界区,
不值得为它多维护一张网格,这一点写在类注释里。

### 2. 同一个 seed 必须逐帧复现

- `src/` 下**禁止 `Math.random()`**,`tests/unit/noMathRandom.test.ts` 会扫描拦截。
- 所有随机走注入的 `Rng`(mulberry32),用 `fork()` 派生子流,这样「地形多消费了
  两个随机数」不会把赛道整个改掉。
- 主循环是定步长累加器,`?test=1` 时**完全不注册 rAF**,只由 `advance(n)` 推进。
- `InputRecorder.record()` 会**就地**把实时输入量化成回放精度。不这么做,M4 的幽灵
  会沿着一条和你实际跑过的略有不同的线走(实测 10 秒漂 1.2 米)。

### 3. 截图回路是这个项目的地基

CI 没有 GPU,WebGL 走 SwiftShader。`npm run shoot` + `tests/visual/smoke.spec.ts`
是 agent **唯一能看见画面**的途径。

**性能预算要盯:** 冒烟测试从 M0 的 27.7 秒涨到现在的 1.4 分钟(CI 上 2.5 分钟)。
大气 shader 和 PMREM 烘焙是主要开销。后处理还没加。**如果这条回路变得太慢,
先停下来解决,不要硬推** —— 它挂了就等于瞎着写代码。

## 五、这个项目吃过的亏(别再踩一遍)

按「只有看图才能发现」的程度排序:

1. **转向左右反了。** 单测断言的是「yaw 与 steer 同号」,而 yaw 正方向到底是左是右
   *正是搞反的那件事* —— 断言和 bug 共用同一个错误前提,83 条测试全绿也拦不住,
   最后靠人试玩发现。**教训:断言物理位置,不要断言内部约定的符号。**
   现在的转向测试断言「车最后跑到哪一边」。
2. **烘环境贴图时天空整个变黑。** `scene.add(sky)` 会把天空从世界场景摘走(three 里
   一个对象只能有一个父节点)。而且黑得很干净,乍看像「天空还没做」。编译、单测、
   截图冒烟(只判像素方差)全过。
3. **地形三角形压在赛道上。** 剔除只按重心判断,11 米的格子只要重心在赛道外就保留,
   而它可能有一半盖在路面上。
4. **贴地阴影不出现。** 扇形三角的绕序反了,整个面朝下被背面剔除。
5. **车漆反射成磨砂玻璃。** metalness 给到 0.55 想「反射天空」,结果金属度高了之后
   基色不再决定颜色、只决定反射色调,车身就没有自己的颜色了。车漆是电介质
   (metalness ≈ 0.15)+ 清漆层。

### 两个测量方法的坑

- **别拿速度差反推侧向加速度。** 车头转动本身会让机体坐标系下的侧向速度以 ω·v 变化
  (0.9 rad/s × 80 m/s = 72 m/s²),撞墙冲量也会混进去。第一次这么量得出 247 g。
  现在 `Vehicle.lateralGripAccel` 直接暴露抓地力实际施加的加速度。
- **测试失败时先找真实原因,别急着放宽容差。** 左右镜像那条差了 0.04°,看着像浮点
  噪声,实际是出生点只有 46 米压平区而车能跑到 48.7 米,左右压到了不同地形。
  缩短行程后 1e-7 的严格容差就恢复了。放宽容差会把真实原因永久盖掉。

## 六、当前手感数值(实测)

改 `tuning.ts` 之后这些会变,`tests/unit/vehicle.test.ts` 和 `grip.test.ts` 里的
区间就是它们的规格书 —— **测试挂了不一定是 bug,但一定意味着手感变了,需要人类确认。**

| 项目 | 值 |
|---|---|
| 0 → 100 km/h | 0.92 s |
| 极速 | 315 km/h |
| 峰值侧向抓地加速度 | 3.80 g(有上限,不减速冲弯会滑出去撞墙) |
| 弯中最低速 | 142 km/h |
| 满舵侧滑角峰值 | 57°(甩尾,不是打转) |
| 赛道长度 | 2.8–3.4 km,10 个 seed 全部可跑完 |

**关键设计:偏航角速度上限由可用侧向力推出(ω = a_lat / v),外加侧滑回正力矩。**
少了任何一个,车都会一打方向就原地打转。

## 八、工作方式

- **分支**:harness 指定固定分支 `claude/m0-scaffold-9daeli`。PR 合并后从
  `origin/main` 重开同名分支继续。
- **提交前必过**:`npm run typecheck` / `npm run test -- --run` / `npm run build` /
  `npm run test:visual`。
- **人类的反馈风格**:给的是现象(「车太飘」「视角偏得离谱」),需要自己去测量、
  定位根因。他会验收手感和画面,这两件事不要自己下结论。
- **额度有限**,他会喊停。停的时候确保工作已提交推送。

### 常用命令

```bash
npm run dev                                     # 本地开发
npm run shoot                                   # 截图(默认 chase 机位、seed 42)
npm run shoot -- --camera=side --throttle=0     # 静止侧视,看载具本身
npm run shoot -- --camera=top --seed=7          # 俯视近景
npm run shoot -- --steer=0.35 --frames=150      # 过弯姿态
npm run shoot -- --no-build                     # 复用现有 dist,连拍时省时间
```

机位:`chase`(玩家视角)/ `side` / `front` / `top`。
`?course=flat` 切回 M1 那块带跳台的平地,调手感时没有赛道干扰更干净。
