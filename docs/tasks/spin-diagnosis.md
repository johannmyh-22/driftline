# 诊断:「一给油就原地打转」

> 现象来自 `docs/HANDOFF.md` 第十三节。这次用轮子级探针实测定位,
> **只诊断,没改任何物理/轮胎/手感数值。** 复现命令与原数据在下面。

## 复现方法与工具

探针脚本 `scripts/spin-probe.ts`(走 `?test=1&seed=N` 确定性步进接口,
逐帧 `advance(1)` + 采一轮子级遥测):

```bash
npm run spin-probe -- --seeds=1337,1,42 --frames=90 --course=race   # 赛道,默认
npm run spin-probe -- --seeds=1337 --frames=90 --course=flat        # 平地对照组
```

产物(已 gitignore,不提交):
- `tests/visual/__output__/diagnostics/seed<N>.csv` —— 每帧每轮逐项原始数据
- `tests/visual/__output__/diagnostics/summary.json` —— 三个 seed 的汇总指标

## 三秒结论

**车打转的根因是「后轮在持续空转、几乎失去全部侧向抓地力」,叠加
「左右后轮载荷不对称 → 纵向驱动力产生净偏航力矩」,一旦有了初始偏航就没有
任何回正机制,于是转速单调放大到 1.98 rad/s。**

拆成两段看:

1. **触发(为什么一开始转)** —— 驱动力全压后轴,左右后轮载荷一旦不对称,
   两轮各自产生的纵向力就不相等,在质心前后的不同力臂上凑出一个净偏航力矩。
   载荷不对称的正交来源是**胎面载荷转移 / 出生点不水平**。
2. **失控(为什么停不下来)** —— 后轮滑移率冲到 **15~80**(设计峰值 0.12,
   超 500 倍),摩擦圆预算被纵向空转吃光,**后轴侧向力只剩 50~250 N(前轮的
   3~15%)**。真车靠后轮侧向力 + 自回正力矩拉住车头;这里没有后轮抓地力,
   就没有回正力矩,侧滑一旦起来就收不住,形成正反馈。

**对照组铁证**:同一辆车、同一个 seed,在**完全水平的平地**上 90 帧
yawRate 恒为 0(后轮左右载荷逐帧对称,纵向力矩两两抵消)。打转**不是**
单条轮子/某个力的固有 bug,而是「驱动力矩 vs 后轮可用抓地力」失配后,
由载荷不对称点燃的失稳。

## 逐轮力/力矩分解(seed 1337,最后 30 帧平均,牛·米)

轮序:0=FL  1=FR  2=RL  3=RR。

| 项 | FL | FR | RL | RR | 左侧/合计偏航 |
|---|---|---|---|---|---|
| **合计 yaw 力矩** | +1775 | +1002 | **−1573** | **+2682** | **净 +3886**(左转) |
| 纵向项(驱动) | −26 | 0 | **−2972** | **+2464** |  后轴纵向净 **+1477** |
| 侧向项(轮胎 fy) | +1938 | +2210 | −60 | −266 |  前轴侧向净 **+631** |
| 悬挂项 | −137 | −1207 | +1459 | +484 | — |

平均(持续空转段):后轮滑移率 **RL=64.8, RR=14.4**(设计峰值 0.12);
后轮侧向力 **RL=50 N, RR=225 N**,前轮 **FL=1529, FR=1741 N**。

**读出什么:**

- **净偏航力矩主要来自后轴的纵向项(+1477)**:左右后轮滑移率差十几倍、
  载荷不对称,两轮纵向力不等,合力绕质心转 —— 这就是触发源。
- **后轮侧向项几乎为零(−60/−266)**:后轴已经完全拿不出抓地力去「拽住」
  车尾,这也是失控放大的生理原因。
- 前轮侧向项(+1938/+2210)是这套系统里**唯一**还在提供稳定反力矩的地方,
  但它们离质心越近越转不动,量级撑不住整台车 —— 于是正反馈胜出。

## 根因链(一句话)

```
左右后轮载荷不对称(出生点/载荷转移)
   → 后轮滑移率冲到 15~80(远过 0.12 峰值,摩擦圆被纵向空转吃光)
   → 后轴侧向抓地力消失(只剩前轴的 3~15%)
   → 纵向力不对称产生净偏航力矩,且无任何侧向回正力矩
   → 侧滑放大,转速单调涨到 1.98 rad/s,车横着走(lateralSpeed 5.49)
```

## 与 HANDOFF 第十三节给出的方向对账

HANDOFF 怀疑的方向里有两条被本探针**实证支持**:

- **「`CAR.driveTorque=2800` 配 `rearDriveBias=1`,扭矩全压后轴,后轮滑移率
  一冲过峰值,摩擦圆预算被纵向吃光,侧向撑不住」** —— 完全证实。后轮滑移率
  15~80、侧向力只剩几分,数字都在这份文档里。
- **「左右两侧是否对称」** —— 探针给出明确答案:**轮子本身左右几何/驱动分配
  是对称的**(平地对照组 yawRate=0 就是证明),**不对称来自载荷**(出生不平 +
  载荷转移),它会随 seed 变。所以不是「左右写反了」那种固定 bug。

HANDOFF 提的候选解法方向(砍 `driveTorque`、调 `SLIP_SPEED_FLOOR`)都没有改,
**这轮只诊断。** `SLIP_SPEED_FLOOR=2.5` 让起步时滑移率分母恒为 2.5、轮速稍一起来
滑移率就很大,是起步空心转的放大器之一;但 90 帧里后轮滑移率到 15~80 是在
6 m/s 时速下依旧成立,所以**主因是驱动扭矩对后轮抓地力的持续性超额**,
不是 `SLIP_SPEED_FLOOR` 一个数能背的锅。
